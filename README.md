# 🎧 Olusia AI Studio

Lokalna aplikacja macOS do konwersji plików audio i wideo, transkrypcji nagrań i generowania fiszek AI z tekstu lub zdjęć.

## Moduły planowane do publikacji
- FFmpeg: wyciąganie MP3 z filmów
- Demucs: separacja głosu i muzyki
- Faster-Whisper: lokalna transkrypcja
- Tesseract + Ollama: OCR i fiszki z lokalnym modelem

Nie używamy płatnego API do podstawowych funkcji.

## Aktualizacje
Źródłem aktualizacji będzie to repozytorium; instrukcja w [GITHUB_AKTUALIZACJE.md](GITHUB_AKTUALIZACJE.md).

**Stan repozytorium:** uprawnienia zapisu działają, ale pełny kod aplikacji i pipeline wydawania paczek nie zostały jeszcze opublikowane. Nie traktuj obecnego repo jako kompletnego instalatora.

## Prywatność
Dane użytkowniczki oraz lokalne modele muszą pozostać na jej MacBooku. Repozytorium jest publiczne i nie powinno zawierać żadnych prywatnych plików.
