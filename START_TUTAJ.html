🟢 Lokalnie • Bez API • Wersja 2.1

🎧 Olusia AI Studio

MP3, izolacja głosu, transkrypcje i fiszki ze zdjęć oraz tekstu.

Masz już działającą starą wersję? Zacznij tutaj! 💜

  1. Zamknij stare Olusia AI Studio (w Terminalu naciśnij Ctrl+C).
  2. W nowo rozpakowanym folderze dwukrotnie kliknij 0_UAKTUALIZUJ_STARA_WERSJE.command.
  3. Wskaż stary folder aplikacji. Skrypt zaktualizuje kod, zachowując biblioteki AI.
  4. W starym folderze kliknij 5_DOINSTALUJ_FISZKI.command. Pobierze lokalny model do fiszek.
  5. Uruchom 2_URUCHOM.command. Gotowe!

Co nowego?

📷 Zdjęcia → tekst → fiszki
Odczyt z JPG, PNG i HEIC, generowanie pytań z odpowiedziami, edycja i nauka.
✍️ Własny tekst → fiszki
Wklej notatki, wybierz ilość i poziom, zapisz zestaw lub wyeksportuj do Anki.
🔄 Aktualizacje ZIP
Nową wersję będzie można wgrywać w zakładce Aktualizacje. Nie tracisz zapisanych fiszek ani modeli.
🖥️ Skrót macOS
Plik 6_UTWORZ_APLIKACJE.command utworzy ikonę aplikacji w katalogu Aplikacje użytkownika.

Nowa instalacja od zera

Najpierw zainstaluj Homebrew, potem uruchom 1_ZAINSTALUJ.command i 5_DOINSTALUJ_FISZKI.command, na koniec 2_URUCHOM.command.

🔒 Prywatność i koszt: modele działają na MacBooku i nie wymagają płatnego API. Internet potrzebny jest przy pobieraniu programów i modeli. Przy odręcznych notatkach OCR może się mylić; sprawdź wynik. GitHub Releases dla przyszłych aktualizacji nie jest jeszcze skonfigurowany. Więcej informacji w README.md.
